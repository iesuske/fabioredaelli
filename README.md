# Portfolio / Progetto Web - Fabio Redaelli

Repository ufficiale per il sito web personale e portfolio di **Fabio Redaelli**, caratterizzato da elementi grafici a tema automotive, tipografia personalizzata e componenti interattivi web.

## 📁 Struttura del Repository

* `index.html` - Pagina principale del sito.
* `site.webmanifest` - Manifesto dell'applicazione web (PWA) per la configurazione del browser e della schermata iniziale.
* `clacson.mp3` - Risorsa audio interattiva (effetto sonoro del clacson).
* `fonts/` - Directory contenente i font personalizzati utilizzati nel progetto.
* `images/` - Raccolta delle risorse grafiche e fotografiche del sito.

## 🚀 Tecnologie Utilizzate

* **HTML5 & CSS3** per la struttura e la formattazione avanzata dei layout.
* **Progressive Web App (PWA)** tramite `site.webmanifest`.
* **Asset multimediali integrati** (audio e font dedicati).
